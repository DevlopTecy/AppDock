CANDY LAND THEME ASSETS
=======================

Source artwork: 964 x 1632 pixels

Folders:
01_backgrounds - full wallpaper and cropped candy-world scenes
02_app_icons   - music, cloud, calendar, gamepad, globe, add, search, expand, close
03_sidebar     - wood sidebar panel and decorative crop
04_header      - title header, category tabs, app count decoration
05_game_cards  - Steam, Epic, Manor Lords, and Add card crops
06_buttons     - top controls and Settings button
07_decorations - strawberry, cat, signpost, cat scene, cafe, lollipop
08_textures    - frosting, wood, sky, water, and castle visual crops

IMPORTANT:
These are raster PNG crops from the generated concept artwork. They are useful
as visual references and quick theme mockup assets, but they are not original
layered/vector source files. Some crops contain baked-in text or neighboring
artwork; inspect and clean them before using as standalone production UI assets.
The complete original concept sheet is included for reference.
